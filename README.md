# 🧮 Calculadora Kotlin (Jetpack Compose)

Aplicativo de calculadora simples desenvolvido em Kotlin utilizando Jetpack Compose para interface moderna e reativa.

## 🚀 Tecnologias utilizadas

* Kotlin
* Jetpack Compose
* Material 3
* Arquitetura MVVM
* StateFlow para gerenciamento de estado

## 📱 Funcionalidades

* Operações básicas: soma, subtração, multiplicação e divisão
* Tratamento de erros:

  * Campos vazios
  * Entrada inválida (letras)
  * Divisão por zero
* Interface responsiva
* Atualização em tempo real dos resultados

## 🧠 Arquitetura

O projeto segue o padrão MVVM:

* **Model**: regras de negócio (cálculos)
* **ViewModel**: gerenciamento de estado e lógica
* **UI (Compose)**: interface declarativa

## 🎯 Objetivo

Projeto desenvolvido para prática de desenvolvimento Android moderno com Kotlin e Jetpack Compose.
